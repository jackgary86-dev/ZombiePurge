# ZombiePurge – Art Generation Master Prompt

Use this to make every piece of art for ZombiePurge look like it belongs to the same game, whether it is
generated by an AI tool (Meshy, Tripo, Rodin, Luma Genie, Midjourney, Stable Diffusion, Blender add-ons) or
made by a person.

**How to use it**

1. Copy the **Global style block** below into your tool first — every single time.
2. Add **one Asset block** from section 3 (or fill in the template in section 4).
3. Add the **Negative prompt** from section 5 if the tool supports one.
4. Check the result against the **Delivery checklist** in section 6 before committing it under `assets/`.

Read this alongside the game design in `README.md` and the ticket plan (Epic I – Art & Assets).

---

## 1. Global style block (paste this first, always)

```
Stylized low-poly game art for "ZombiePurge", a 3D zombie-smashing driving game.
Chunky, toy-diorama proportions with slightly exaggerated shapes; strong, readable
silhouettes that stay clear from 300 metres away. Flat-shaded faces with soft
hand-painted gradient textures, gentle ambient occlusion baked into vertex color,
no photorealism, no high-frequency detail. Saturated but grimy palette: warm
rust-orange and blood-red accents against desaturated greys, teals and olive
greens. Cartoon violence only: bright stylised splats, no anatomical gore.
Clean topology, single object, centered at origin, standing on the ground plane,
metres scale (1 unit = 1 m), Y up, facing +Z. Neutral lighting, no background,
no text, no watermark.
```

**Why this look:** low-poly models keep 200+ zombies at 60 fps in a browser (ticket H1), silhouettes
sell the "spot them before they spot you" gameplay at long range, and a stylised style hides the fact
that a horde reuses a handful of models.

## 2. Technical rules (the code depends on these)

| Rule | Value |
|---|---|
| Format | glTF binary `.glb`, Draco or meshopt compressed; textures as KTX2 (or PNG for source) |
| Scale | Metres. Car ≈ 4.0 m long × 1.8 m wide; zombie ≈ 1.8 m tall; Brute 2.4 m; Tank 3.2 m; Boss 5 m |
| Axes | Y up, **+Z is forward**, +X is the model's left side (right-hand rule) |
| Origin | Car: centre of the chassis at wheel-axle height. Characters and props: at the feet / base |
| Triangle budgets | Car body 6–8k · upgrade part ≤ 1.5k · zombie 2.5–3.5k (LOD1 1.2k, LOD2 400) · small prop ≤ 300 · house / large prop ≤ 2k · Boss ≤ 10k |
| Textures | Car 1024², zombie 512², props share a 1024² atlas per environment kit. Albedo + optional normal + ORM (occlusion/roughness/metal) |
| Materials | One material per model where possible; PBR-safe values (metal 0 or 1, roughness 0.5–1.0) |
| Variants | Hordes must not look identical: provide colour/texture variants or a tint mask so code can recolour |

### 2.1 Car attachment points (ticket I3 → used by D14 "upgrades visible on the car")

The car `.glb` must contain **empty nodes** with exactly these names, positioned on the base car:

```
wheel_FL  wheel_FR  wheel_RL  wheel_RR      (wheel centres; wheels are separate meshes)
mount_roof                                  (roof weapon: machine gun / rocket launcher)
mount_front                                 (front ram / spikes / flamethrower)
armor_front  armor_rear  armor_left  armor_right
tank_fuel                                   (bigger fuel tank, rear)
nitro_left  nitro_right                     (nitro bottles, rear sides)
headlight_left  headlight_right
exhaust
```

Damage states: three versions of the body mesh — `clean`, `dented`, `wrecked` — with identical attachment
points so upgrades keep fitting.

### 2.2 Zombie rig and animations (ticket I5)

Humanoid skeleton (Mixamo-compatible naming is fine). Every rank needs these clips, named exactly:
`idle`, `walk`, `run`, `attack`, `hit`, `death`. Runner gets a fast sprint `run`; Brute/Tank/Boss get a
heavy stomp `walk`. Death should end in a pose that reads as a pile on the ground (ragdoll is optional).

## 3. Asset blocks

Paste one of these after the Global style block.

### 3.1 Player car

```
ASSET: player car, base model.
A beat-up but tough late-90s station wagon / muscle-car hybrid, boxy and wide, low stance,
oversized chunky tyres, exposed roof rack, welded plate patches, mismatched door.
Colour: faded rust-orange body (#c8402e) with charcoal (#2b2b30) trim and a cream stripe.
Separate wheel meshes. Three body versions: clean, dented (crumpled hood, one cracked
window), wrecked (missing bumper, smoke-stained, roof caved slightly).
Include named empty nodes for wheel_FL/FR/RL/RR, mount_roof, mount_front, armor_*,
tank_fuel, nitro_left/right, headlight_left/right, exhaust.
```

### 3.2 Zombies (one block per rank)

Common line for all zombies:
```
ASSET: zombie, rank {RANK}. Humanoid, rigged, animations idle/walk/run/attack/hit/death.
Torn everyday clothes, greenish-grey skin (#8a9a7a), dark sunken eyes, exaggerated
posture. Three colour variants of clothing for horde variety.
```

| Rank | Extra description |
|---|---|
| **Walker** | Slow shambler, hunched, one dragging leg, average build, 1.8 m. Office worker / suburban clothes. |
| **Runner** | Lean and wiry, forward-leaning sprinter pose, torn tracksuit, bare feet, 1.75 m. |
| **Spitter** | Bloated neck and jaw, glowing acid-green throat sac (#9cff3a emissive), thin limbs, 1.8 m. Spits acid. |
| **Brute** | Hulking 2.4 m, huge shoulders and fists, broken shackles, thick hide; hits the car hard. |
| **Tank** | 3.2 m armoured giant, skin cracked like dried mud, plated back, stubby head, slow stomp. |
| **Boss** (map 5) | 5 m lab mutant: exposed ribs, tubes and a glowing core (#ff5a1f), multiple arms, unique idle. |
| **Ice zombie** (map 4 variant) | Any rank retextured: frost-blue skin, icicles on limbs, frozen breath. |

### 3.3 Upgrade parts (ticket I4) — each must sit on its attachment point

```
ASSET: car upgrade part, {PART}, tier {1|2|3}. Fits the ZombiePurge player car at
attachment point {NODE}. Higher tiers are bigger, more welded plates, more warning
stripes and exposed bolts. Chunky, readable at a glance.
```

| Part | Node | Tiers |
|---|---|---|
| Machine gun | `mount_roof` | 1 single barrel → 2 twin barrels → 3 minigun |
| Shotgun | `mount_roof` | 1 → 2 (sawn-off double) |
| Rocket launcher | `mount_roof` | 1 four-tube → 2 six-tube |
| Flamethrower | `mount_front` | 1 → 2 (twin nozzle, bigger tank) |
| Front spikes / ram | `mount_front` | 1 bumper bars → 2 spikes → 3 plough blade |
| Armor plating | `armor_*` | 1 sheet metal → 2 riveted plates → 3 heavy slabs |
| Tyres | `wheel_*` | road → off-road knobbly → snow tyres with chains |
| Fuel tank | `tank_fuel` | 1 jerry cans → 2 drum → 3 twin drums |
| Nitro | `nitro_left/right` | 1 single bottle → 2 twin bottles |
| Headlights | `headlight_*` | 1 stock → 2 light bar |

### 3.6 VFX sprites and meshes (I9)

Small square sprite sheets (4×4, 512²) or simple meshes: muzzle flash, tracer, fire tongue (flamethrower),
explosion puff, acid glob + splash, blood splat (bright, cartoon; provide a "low-gore" grey dust
alternative), tyre smoke, dust trail, snow spray, sparks, coin burst.

### 3.7 UI icons and HUD (I10)

```
ASSET: flat game UI icon, {NAME}. Bold 2-colour silhouette on transparent background,
rounded corners, 4 px outline, readable at 32 px. Palette: cream #f4e9d8 on charcoal
#2b2b30 with rust-orange #c8402e accent. Tiers shown by 1–3 small chevrons.
```
Icons: coin, fuel can, wrench (repair), heart (HP), shield (armor), engine, tyre, machine gun, shotgun,
rocket, flame, spikes, nitro, radar, headlight, skull per zombie rank, distance (road arrow), pause,
settings, controller, keyboard.

### 3.8 Logo and key art (I11)

```
ASSET: game logo "ZombiePurge". Heavy slab lettering with chipped metal edges, tyre-track
scar through the letters, rust-orange #c8402e fill with cream #f4e9d8 outline, a small
zombie hand grabbing the last E. Horizontal and stacked versions, transparent background.
```
Key art: the player car mid-jump over a horde at sunset on the Suburbs map, low camera angle, motion
blur on tyres, coins bursting from a squashed zombie. 16:9 and 9:16 versions.

### 3.9 Skyboxes (I8)

One equirectangular 4096×2048 skybox per map, day and night variants, matching the palette table.
Stylised painted clouds, no lens flares, no text.

```

Size: about {metres}. Origin at {base|centre}. Facing +Z.
Shape notes: {2–4 strong silhouette features}.
Colours: {2–3 hex values from the map palette}.
Variants: {number and how they differ}.
Budget: under {triangles} triangles, {texture size} texture.
Deliver: .glb with {named nodes / animation clips if any}.
```

## 5. Negative prompt

```
photorealistic, realistic skin, high-poly, sculpted micro detail, realistic gore, blood
pools, viscera, text, watermark, logo of a real brand, background scenery, multiple
objects, floating parts, non-manifold geometry, inverted normals, mirrored UVs,
translucent materials, lens flare, depth of field
```

---

## 6. Delivery checklist

- [ ] `.glb` opens in https://gltf-viewer.donmccurdy.com/ with no errors
- [ ] Scale checked against the car (4 m) or a 1.8 m human
- [ ] Origin and forward axis correct (+Z forward, Y up)
- [ ] Triangle count within budget (viewer shows it)
- [ ] Attachment-point nodes / animation clip names match section 2 exactly
- [ ] Colour variants or tint mask provided for horde assets
- [ ] Saved as `assets/models/{category}/{name}_{variant}.glb` with textures next to it
  (`{name}_albedo.png`, `{name}_normal.png`, `{name}_orm.png`), lowercase, no spaces
- [ ] Licence noted in `assets/LICENSES.md` (generator or artist, terms)

Categories: `car`, `parts`, `zombies`, `env/suburbs`, `env/desert`, `env/industrial`, `env/frozen`,
`env/lab`, `vfx`, `ui`, `sky`.
